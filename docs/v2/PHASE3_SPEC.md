## 1. 지금까지 확정된 것

- 게시 검정은 로그수익률 평균의 차이였다. 단순수익률로는 표본 내 0/12. 변형에 따라 0–2/12, 2017–2024 구간은 모든 변형에서 0/12.
- 2017–2024 는 hold-out 이 아니다 (Lock D 문서에 그 구간 t 가 이미 있다). Russell 3000 은 구현되지 않았다. 차입료는 한 달치만 뺐다.
- 12셀 그리드·방향·업종 정의가 수익률 계산 전에 고정된 것은 확인됐다 (Lock C 파일 시각 < 첫 결과).
- 남는 서술: 발표 일정이 불규칙한 기업은 로그 중앙값 수익률이 낮고 분산이 크다. Chambers–Penman 방식의 발표 3일 창은 early − late +0.66% (t 5.8, 2000–2016) 로 나왔으나 원 정의 확인이 남았다.

## 3. 보조 사양 (전부 돌리고 전부 보고)

- B1 유니버스를 CRSP 보통주 전체로 (Russell 근사 밖 초소형주 포함).
- B2 코호트 단위 검정 (게시 방식의 통계량을 단순수익률로, NW).
- B3 게시 구성 그대로 (로그, 현재 CUSIP 연결) — 참조용 재현.
- B4 composite (주 셀 4개) 의 달력 시간 Sharpe: 총 / 호가 스프레드 차감 / 차입료 포함.

## 4. 확인 검정

- D1 **미관측 구간이 있는가**: dump 의 CRSP (`dsf_v2` 는 2025-12-31 까지) 와 Compustat `fundq` 로, Phase 0 전체 표본 (2025년 1–4월 코호트 포함, D9) 에 들어가지 않았던 코호트가 몇 개인지 센다. 보유 창이 닫힌 미관측 코호트가 12개월 미만이면 "표본 외 검정 불가" 로 적고 수만 보고한다. 12개월 이상이면 주 사양 12셀을 그 구간에서 돌린다.
- D2 **Strategy B (Chambers–Penman)**: 원 논문의 기대 발표일 정의 (원문 또는 신뢰할 수 있는 2차 문헌에서 확인하고 출처를 적는다) 와 발표 3일 창으로 다시 계산한다. 분위 방향을 바로잡는다 (D7). 2000–2016 과 2017–2024.
- D3 **기제 점검 (탐색, 사전 등록 밖임을 표기)**: 로그 스프레드가 분산 차이에서 나온다는 1차 해석 (D1) 을 표준적인 결과 변수로 잰다. 가설 하나: 신호 최상위 5분위 기업은 이후 12개월 안에 실적 사유 상장폐지 (CRSP delisting code 400–599) 될 확률이 높다.
  - 2000–2016 에서 추정하고 2017–2024 에서 같은 사양으로 확인한다.
  - 선형확률모형, 종속 = 12개월 내 실적 사유 상장폐지, 설명 = 5분위 더미 (Q5 vs Q1), 통제 = log 시가총액·직전 12개월 수익률 변동성·연도 고정효과. 기업 군집.
  - 이 항목은 수익률 신호를 살리려는 것이 아니다. 결과가 어떻든 "탐색" 으로 표기해 보고하고, 사양을 바꿔 다시 돌리지 않는다.
- D4 **Table 6 (1주 지연)·Table 8 (40셀)** 을 같은 표본끼리 비교해 다시 만든다.
